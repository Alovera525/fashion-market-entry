# fashion-market-entry

面向时尚、服饰、箱包品牌的新市场进入调研 Skill。它把“某品牌能不能进入某个国家或地区”拆成可核验的市场判断、风险闸门和落地策略，避免把估算、代理指标或未确认的信息写成事实。

> 当前版本：`0.1.1` · 兼容：Claude Code / Codex · 许可证：MIT

## 适合处理什么

| 场景 | 产出 |
|---|---|
| 判断品牌能否进入某市场 | 执行摘要、否决条件和章节大纲 |
| 制定新国家市场策略 | 有来源、可追溯的 Markdown 调研文档 |
| 选择平台、品类、价格带和目标人群 | 带假设、限制条件和验证动作的建议 |
| 分析现有库存能否进入某市场 | 货盘与当地需求的匹配判断 |
| 审查已有市场报告 | 结构、证据、逻辑、重复和执行性检查 |

不适用于单品文案、日常运营排期、具体 SKU 清单、精确预算或纯财务测算。

## 核心方法

1. 先确认委托方身份、货盘前提、目标市场、时间窗、平台与预算量级。
2. 有现成库存时，先分析货盘，再判断当地市场是否匹配。
3. 把数字区分为可直接引用、需标注的推算值、尚未确定且不能给数三类。
4. 先检查授权、市场准入和品牌现有渠道等否决性风险。
5. 将市场证据、判断、限制条件和行动建议连成闭环。
6. 第一轮先交付“执行摘要 + 章节大纲”，方向确认后再生成完整报告。

## 如何使用

可以直接描述需求，也可以同时提供库存 Excel、CSV、现有市场报告、品牌资料、授权范围或竞争品牌名单。

将文件上传为附件，或者放进当前工作区，并在需求中说明文件名即可。

### 示例一：分析现有库存

```text
我是一个授权经销商，准备进入马来西亚市场，计划3个月内上线。

附件 inventory.xlsx 是目前可用的服装和箱包库存。请先分析货盘结构，再判断哪些品类适合马来西亚、哪些不适合，并研究优先平台、目标人群、价格带和主要风险。

这批库存还可能分给其他国家，分配比例尚未确定，请不要自行估算。

第一轮先给我执行摘要和章节大纲，确认后再完成报告。
```

### 示例二：从零研究新市场

```text
我们是一个女装品牌，计划进入越南市场，目前还没有确定具体选品。

请判断这个市场是否值得进入，应该优先选择什么平台、品类和目标人群，以及需要提前验证哪些风险。

先完成必要的开工问题，再给我执行摘要和章节大纲。
```

### 示例三：审查已有市场报告

```text
请审查附件 market-report.md。

重点检查数据来源、推算值、代理指标、授权假设、逻辑断层、重复内容和建议是否能够执行。

不要直接重写整篇，先列出必须修改的问题、原因和建议改法。
```

## Skill 工作流

| 阶段 | 主要动作 | 交付 |
|---|---|---|
| 1. 开工判断 | 确认身份、货盘、市场、时间和平台条件 | 明确研究边界 |
| 2. 方向确认 | 建立关键判断与否决点 | 执行摘要 + 章节大纲 |
| 3. 调研与分析 | 查证市场、平台、竞品、风险和本地化 | 带来源的完整报告 |
| 4. 交付验证 | 核对数字、逻辑、一致性和可读性 | 数据缺口与待办清单 |

## 使用边界

- 市场数据、法规、平台政策和价格会变化，使用时必须重新查询并注明日期。
- 推算值必须展示假设与算式，不能把建议测试值写成市场事实。
- 社媒关注、榜单和评分只能作为代理指标，不能冒充真实销售份额。
- 未确定的库存分配比例和投放预算不会被自行估算。
- 本 Skill 提供市场研究与关键策略结论，不替代当地法务、税务或商业授权确认。
