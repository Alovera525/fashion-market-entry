# fashion-market-entry

面向时尚、服饰、箱包品牌的新市场进入调研 Skill。它把“某品牌能不能进入某个国家或地区”拆成可核验的市场判断、风险闸门和落地策略，避免把估算、平台观察或未确认的信息写成事实。

> 当前版本：`0.1.2` · 兼容：Claude Code / Codex · 许可证：MIT

## 适合处理什么

| 场景 | 产出 |
|---|---|
| 判断品牌能否进入某市场 | 执行摘要、否决条件和章节大纲 |
| 制定新国家市场策略 | 有来源、可追溯的 Markdown 调研文档 |
| 选择平台、品类、价格带和目标人群 | 带假设、限制条件和验证动作的建议 |
| 分析现有库存能否进入某市场 | 货盘与当地需求的匹配判断 |
| 审查已有市场报告 | 结构、证据、逻辑、重复和执行性检查 |

不适用于单品文案、日常运营排期、具体 SKU 清单、精确预算或纯财务测算。

## 核心方法

1. 先确认委托方身份、货盘前提、目标市场、时间窗、平台与预算量级。
2. 有现成库存时，先分析货盘，再判断当地市场是否匹配。
3. 区分可核实事实、推算值和无法核实的平台内信息。
4. “没有官方店”或“没人做这个价格带”只能作为待验证假设。
5. 气候、人口和品类逻辑只能说明属性，真实需求必须由成交数据证明。
6. 获得真实成交价后，回库存表核算可售数量、所需折扣和毛利条件。
7. 第一轮先交付“执行摘要 + 章节大纲”，方向确认后再生成完整报告。

## 如何使用

可以直接描述需求，也可以提供库存 Excel、CSV、现有市场报告、品牌资料、授权范围、竞品名单或平台截图。

将文件上传为附件，或者放进当前工作区，并在需求中说明文件名即可。

涉及平台官方店、销量、关注量、评分、榜单或实际价格时，建议同时提供平台内截图。无法核实的平台事实会被列为待验证项，不会被用来支撑市场结论。

### 示例一：分析现有库存

```text
我是一个授权经销商，准备进入马来西亚市场，计划3个月内上线。

附件 inventory.xlsx 是目前可用的服装和箱包库存。请先分析货盘结构，再判断哪些品类和款式适合当地市场，并研究优先平台、目标人群、价格带和主要风险。

附件还包括 Shopee 官方店和搜索结果截图，请结合实际销量和价格判断需求，不要只看商品属性。

这批库存还可能分给其他国家，分配比例尚未确定，请不要自行估算。

第一轮先给我执行摘要和章节大纲，确认后再完成报告。
```

### 示例二：从零研究新市场

```text
我们是一个女装品牌，计划进入越南市场，目前还没有确定具体选品。

请判断这个市场是否值得进入，应该优先选择什么平台、品类、款式和目标人群，以及需要提前验证哪些风险。

如果无法确认平台官方店、销量或价格，请明确列为待验证项，不要把“未检索到”写成市场机会。

先完成必要的开工问题，再给我执行摘要和章节大纲。
```

### 示例三：审查已有市场报告

```text
请审查附件 market-report.md。

重点检查数据来源、推算值、平台内事实、代理指标、授权假设、需求证据、逻辑断层、重复内容和建议是否能够执行。

特别检查报告有没有把“查不到”“没人做”或“气候适合”直接写成市场机会。

不要直接重写整篇，先列出必须修改的问题、原因和建议改法。
```

## Skill 工作流

| 阶段 | 主要动作 | 交付 |
|---|---|---|
| 1. 开工判断 | 确认身份、货盘、市场、时间和平台条件 | 明确研究边界 |
| 2. 方向确认 | 建立关键判断与否决点 | 执行摘要 + 章节大纲 |
| 3. 调研与分析 | 查证市场、平台、成交、竞品、风险和本地化 | 带来源的完整报告 |
| 4. 库存验证 | 用真实价带核算库存数量、折扣与品类结构 | 货盘可行性结论 |
| 5. 交付验证 | 核对数字、证据、逻辑和可读性 | 数据缺口与待办清单 |

## 使用边界

- 市场数据、法规、平台政策和价格会变化，使用时必须重新查询并注明日期。
- 无法核实的平台内事实不会被推测，也不会用于支撑市场结论。
- “没有官方店”或“没人做”在实测前只能作为假设，不能直接定义为市场机会。
- 气候适配、人口结构和价格空位不能代替真实成交需求。
- 社媒关注、榜单和评分只能作为代理指标，不能冒充真实销售份额。
- 未确定的库存分配比例和投放预算不会被自行估算。
- 本 Skill 提供市场研究与关键策略结论，不替代当地法务、税务或商业授权确认。
