# 本地化核查清单

写第二章（本地消费习惯与产品细节）和第七章（本地化 Tips / 消费者偏好 / 文化禁忌）时逐项过。

---

## 一、气候 × 品类

问三个问题：

1. **年均温与最冷月均温**是多少？有没有真正的温差？
2. 雨季有多长？是否影响出行与穿着？
3. 有没有高海拔或高纬度地区构成例外市场？

判断规则：

- 全年无温差的热带市场 → 秋冬服装在平原地区**没有自然需求**，会成为死货
- 但**包袋、配饰的"秋冬"往往是设计季而非气候属性**。判断依据是材质：有呢料、毛绒、厚重内衬的排除；PU、涤纶、皮革的全年可售
- 只有明确的高海拔/山区市场才为重外套单独留货，且量要小

产出：一句"哪些品类是全年货、哪些没有自然需求、哪些需要材质级判断"。

## 二、尺码与退货

网购退货的头号原因，也是服装线上化的最大摩擦点。

- [ ] 本地语尺码表（不能只放英文/原产国尺码）
- [ ] 统一使用厘米（或当地通用单位），并全站一致
- [ ] 模特身高体重 + 试穿尺码
- [ ] 版型标签（合身/宽松/oversize）
- [ ] 短视频试穿，最好含不同身材对比
- [ ] 包袋补充：真人比例、容量、重量、内层结构、五金、包装配件

**尺码风险决定品类顺序**：包袋和小皮具没有尺码问题，通常是风险最低的首购入口；服装要优先选尺码相对完整、版型宽容的款式。

## 三、支付

- [ ] 当地主流支付方式是什么？渗透率如何？（电子钱包 / 二维码 / 银行转账 / 分期 / COD）
- [ ] 目标平台**实际开放**哪些？（平台支持 ≠ 你的店铺资格已开通，要分清）
- [ ] 有没有不可谈判的必备项？（某些市场的主流钱包不接等于放弃大半流量）
- [ ] COD 的处理策略

**COD 要按单品价格分级**：低客单价开、高客单价关。COD 拒收率、地址失败、退件必须单独监控——它们不是物流问题，是利润问题。

## 四、收货与履约

- [ ] 宅配为主还是自提/代收点为主？
- [ ] 平台自提服务是否有资格开通？
- [ ] 承运商按什么选？——准时率、破损率、偏远地区覆盖、成本。**不要默认某一家快递一定最好**
- [ ] 跨境发货的税费、清关责任、退货路径是否核清？

写进文档的核心判断：**消费者要的是履约确定性**——准时发货、可追踪、及时妥投、清楚的退换货规则，比"指定哪家快递"重要得多。

## 五、促销节奏与节庆日历

### 发薪日节奏

很多市场的消费高度集中在发薪日前后（常见为每月中和月末双峰）。做法是**集中投放而非平均分配**。还要查有没有法定的年终双薪之类的制度性消费高峰。

### 节庆日历

至少提前 **4–6 周**准备。分三类：

| 类型 | 例子 | 处理方式 |
|---|---|---|
| 平台大促 | 9.9 / 11.11 / 12.12 | 纯商业节点，可放开做 |
| 商业化节日 | 圣诞、跨年、年末礼赠 | 常规促销逻辑 |
| **文化/宗教/王室节日** | 泼水节、水灯节、开斋节、母亲节/父亲节 | 带文化语境，**不能当纯促销标签** |

第三类的规则：可以做应景内容和限时权益，但不戏谑仪式，不把纪念日直接包装成"清仓日"。

### 大促准入

只有**库存深度、价格、客服和履约能力都达标**的 SKU 才进大促。否则流量会放大超卖、低毛利和差评——大促把所有问题按比例放大。

## 六、语言与内容

- [ ] 商品标题、卖点、状态、退换货、尺码信息用什么语言？
- [ ] 品牌名、系列名、款号保留英文还是本地化？
- [ ] 客服、社媒、直播用什么语言？（可能与商品页不同——例如商品页纯英文、社媒用混合语）
- [ ] 有没有"不适合用于品牌向内容"的语言变体？

内容配置的基线：每个核心 SKU 至少一条试穿、一条搭配、一条尺码或容量答疑。

**内容要分人群测试**，不要只追热门标签：年轻人群测趋势与一件多穿，主力人群测通勤与社交场景，成熟人群测品质、容量与经典搭配。

## 七、折扣措辞与价格宣传合规

**这一项各市场差异极大，必须逐个市场确认，不能跨市场复用。**

已知的差异案例：

- 有的市场"清仓"是负面词，法规也对折扣宣传有严格限制
- 有的市场二手/尾货文化已经去污名化，"authentic outlet finds / up to 70% off"反而是加分项
- 有的市场对原价标示有明确法规（必须是真实曾经售价、需要持续一定时长）

核查项：

- [ ] "清仓/出清/开仓/outlet"这类词在当地是加分还是减分？
- [ ] 原价标示的法规要求是什么？
- [ ] 不能制造虚假原价或夸大折扣（这条各地通用）
- [ ] 必须如实披露商品年份、状态、包装、售后

**折扣叙事的通用原则**：不能只写原价和折扣率。必须同时证明授权、商品状态和售后价值，否则会被理解为又一个低价卖家。

## 八、正品与信任

在假货担忧高的市场，信任门槛比价格门槛更高。

- [ ] 授权证明怎么展示？
- [ ] 首批真实图文评价怎么积累？（零评价商品在很多市场直接被跳过）
- [ ] 商品状态（旧季/新品/包装完整度）怎么如实说明？
- [ ] 有没有当地高频的"信任词"可以自然使用？

分工原则：**精修图负责品牌感，买家秀、实拍、试穿、容量与细节图负责解决正品、状态和尺码疑虑**。两者都要有。

## 九、文化与营销禁忌

写这一节的原则：**给边界，不给口号**。网上流传的禁忌说法大量是过度简化的，照抄会让文档显得外行，也会不必要地砍掉可用素材。

通用核查项：

1. **宗教符号**：宗教造像、宗教场所、宗教人士不能当普通时尚道具。不印在服装鞋履上；不让模特踩踏、跨越或用脚/鞋底指向宗教或王室相关图像；宗教场所拍摄遵守着装与现场礼仪。
2. **王室与政治**：不借王室、政治议题做促销。避免使用王室肖像、徽记、相似造型、称谓和政治符号。相关纪念日的内容需本地法务或文化审核。
3. **节庆的文化语境**：见上文第五节第三类。
4. **IP 与素材授权**：不要未经授权使用卡通 IP、明星同款、音乐和热门素材。**热门不等于可商用。**
5. **颜色与符号**：这是最容易过度简化的一类。写法参考——

> "[某颜色]是[某禁忌]，所以不能做主图"属于过度简化。该颜色也与[其他语境]有关；普通商品可以使用，但涉及[王室纪念/哀悼/重大公共事件]时应由本地团队审核语境。

6. **服务语气**：客服先确认问题，再给解决选项和时间。不公开争辩，不用强硬、讽刺或命令式表达。语气规范在部分市场属于品牌风险而非小事。

**收尾判断**：任何需要本地文化判断的事项，标注"需本地团队审核"，不要写成可以远程决定的规则。
