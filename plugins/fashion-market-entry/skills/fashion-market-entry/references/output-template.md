## 开头·关于这份文档

紧跟标题，五行以内。**这一块和下面的一页结论，是客户唯一保证会读完的部分。**

```
**读者**：[决策方] + [执行团队]。
**用途**：[某某站]立项决策依据；通过后作为执行基准。
**否决点**：第[N]章。[三项硬前提]，任一不成立则第[N+1]章之后不执行。
**比价基准**：本盘售价中位 [数字]（[换算]）。
**不含**：SKU 选品、月度排期、关税测算。
**怎么读**：只有 5 分钟 → 一页结论；要拍板 → 加读第[N]章；要执行 → 加读第七章 + 文末两张清单。
```

五个字段的作用：

- **读者** —— 决定语气和详略。给客户高层看的和给执行团队看的详略不同；如果两者兼有，就明说兼有
- **否决点** —— 提前告诉读者哪一章能一票否决，他就知道该先读哪里
- **比价基准** —— 全文所有价格比较的锚，放在最前面读者才有参照
- **不含** —— 防止客户拿这份文档去要它本来就没打算解决的东西
- **怎么读** —— 让读者自己选深度。头晕往往不是因为长，是因为不知道哪些可以不读

## 开头·一页结论

编号表格，两列：结论 + 详见章节。

| **\#** | **结论** | **详见章节** |
|---|---|---|
| **1** | **[做不做 + 一句话打法]**，前提是第[N]章[几]项成立 | **N / 7.1** |
| **2** | **[主推什么]。** [资源占比] | **3.1 / 6.1** |
| **3** | **[什么是红海]**，降为[什么角色] | **3.1** |
| **4** | **[平台主次]**（带一个决定性数字） | **1.2 / 7.3** |
| … | | |

**硬规则：**

1. **纯干货，不写解释性文字。** 解释是正文的事。一页结论里出现"因为…所以…"就说明这条该压缩了。
2. **每条都要能独立成立。** 读者只看这一行，不看正文，也要知道该做什么。
3. **条数控制在 12–16 条。** 少于 10 条说明漏了东西，多于 18 条说明混进了细节。
4. **每条挂"详见章节"。** 这是一页结论和正文之间的索引，也是核对一致性的抓手。
5. **顺序按决策重要性，不按章节顺序。** 第一条永远是"做不做"。

**必须进一页结论的类型：**

- 做不做，以及前提条件
- 主推品类与资源分配
- 平台主次
- 地域/季节分盘的硬边界
- 合规与税务的硬约束（已生效的法规、已取消的红利）
- 渠道结构性风险（谁把控着渠道、谁在抢同一个心智位）
- 第一人群与那句最核心的消费者洞察
- 时间窗口（哪个季度是唯一窗口、错过会怎样）
- 最高风险的文化禁忌

**写完后必做**：逐条回正文核对措辞。最常见的错是一页结论说"A 平台优势更大"、正文却写"B = 主战场"。

## 开头·口径基准段

不设章号，3–5 行，紧跟一页结论。货币符号位置与千位分隔符的规则见 SKILL.md 写作硬规则。

写四件事：

1. **汇率锚点**：`¥1 ≈ [X][当地货币]`（注明取数月份），并给一个直觉锚点如 `100.000₫ ≈ ¥26`
2. **本盘商品价格基准表**：吊牌价 / 售价 / 最低价的加权中位，双币种。后文所有比价以此为准
3. **口径约定**：后文的市场规模数字是零售额还是 GMV、含不含税、覆盖线上还是全渠道
4. **本位说明**：一句话说明为什么用这个货币做对照

示例（越南，注意点分隔）：

> 汇率：¥1 CNY ≈ 3.866₫ VND。直觉锚：100.000₫ ≈ ¥26；1.000.000₫ ≈ ¥259。
> 本盘商品价格（加权中位）：吊牌 ¥799 / 3.089.000₫；售价（吊牌 40%）¥319 / 1.233.000₫；最低价（吊牌 20%）¥159 / 615.000₫。
> 后文所有与竞品、平台的价格比较均以这三个数为基准。

**为什么必须放在最前面**：读者看到后面任何一个本地价格，都能自动换算判断"贵不贵"。锚点不给，全篇数字对中文读者就是抽象符号。

## 第一章 市场基本盘

### 1.1 购买力与地域分布

先给全国数据，再给首都圈/核心都市圈数据，两者的差值就是投放地域优先级的依据。

必查：人均 GDP、家庭月均收入（全国 vs 首都圈）、城镇化与收入分布。

**输出：线上投流地域排序**（这是本节的产出，不是可选项）

```
- P1：[首都及都市圈]（收入、品牌认知、平台消费和内容触达更集中）
- P2：[区域中心城市]（年轻消费者与内容测试价值）
- P2：[旅游城市]（若品牌已有旅游零售认知，但需说明应瞄准常住者还是游客）
```

旅游城市要特别注明：如果委托方没有当地线下门店，旅游客流吃不到，应优先瞄准当地常住者。

**若两个核心城市在气候或审美上有实质差异，这里就要说清"不合并成同一个投放包"**，并指向第五章的南北/东西差异表。

### 1.2 品类市场规模与趋势

表格结构：

| 品类 | 当地线上年销售额 | 线上化程度 |
|---|---|---|
| 时尚整体 | 本地货币（括注美元或人民币） | 百分比区间 |
| 其中服装 | | 占时尚大类比例 |
| 包袋及配饰 | | |
| 其中珠宝手表 | | |

同时补四项：

- **近 3 年增长趋势**：给年复合增速或逐年数字，判断是顺风还是逆风市场
- **平台 GMV 份额 + 同比变化**：变化方向比绝对值更重要（"由 61% 下滑到 53%"和"53%"是两个信号）
- **品类层面的平台份额**：全市场份额和时尚品类份额可能方向相反，**以品类份额为准**
- **官方店/Mall 店的店铺数占比 vs GMV 占比**：这一对数字直接说明市场是否向"官方授权"聚拢

### 1.3 客单价与价格错配

平台通常不公布客单价，用公开数据推算并把算式露出来：

| 项目 | 数值 | 折合 |
|---|---|---|
| 平台 GMV | | |
| 销量 | | |
| **平均单品价** | **GMV ÷ 销量** | |

> 按每单 1.4–1.6 件的行业经验区间计算，客单价约 [区间]。

然后做**错配比对**，差几倍写几倍：

> 单品口径：[本盘售价中位] ÷ [平均单品价] = [N] 倍；订单口径 = [M] 倍。

结论落到引流款：给出引流款目标价位（市场平均单品价的 1.5–2.6 倍，溢价由品牌身份支撑），并**反推回吊牌上限**，注明盘内符合条件的商品数量待核对。

### 1.4 价格带假设

三档结构：

| 档位 | 价格区间 | 折合 | 承担角色 |
|---|---|---|---|
| 引流款 | | | 破零与评价积累 |
| 主成交带 | | | 主力品类 |
| 高客单带 | | | 需更强正品证明、实拍与分期承接 |

必写一句话：

> 以上为建议测试价梯，不是市场平均价格，最终须按吊牌、最低售价限制和广告后毛利核算。

## 第二章 本地消费习惯与产品细节

固定用三列表，六个环节。每行必须落到动作——这个结构的作用就是防止写成消费者观察散文。

| 环节 | 本地特征 | ACTION |
|---|---|---|
| **气候** | 温度带、雨季长度、有无温差、湿度 | 哪些品类是全年货、哪些没有自然需求 |
| **尺码** | 网购退货的高风险点 | 本地语尺码表 + 厘米 + 模特身高体重 + 版型标签 + 试穿视频 |
| **支付** | 主流支付方式与渗透率 | 展示平台实际开放的支付方式；COD 拒收要单独监控 |
| **物流** | 时效标配、二三线时长 | 按准时率、破损率、偏远覆盖选承运商 |
| **促销** | 发薪日节奏、大促心智、年度峰值 | 用发薪日与平台大促做限时权益，设定最低成交价 |
| **内容** | 短视频/直播/社交对发现的影响 | 每个核心 SKU 至少一条试穿、一条搭配、一条尺码答疑 |

**气候那一行是杀伤力最大的一行**。热带市场（全年无温差）意味着秋冬服装在平原地区没有自然需求——这可能直接砍掉一半货盘。但注意两点：

1. 包袋的"秋冬"往往是**设计季而非气候属性**，要看材质（有无呢料、毛绒）再决定是否排除，不要按季节标签一刀切
2. **有真实冬季的区域要单独开盘，并划清三条边界**：只在哪些地区成立、只到哪一层（轻外层还是厚外套）、窗口几个月

⚠️ **不要给可用件数或占比的估算**（SKILL.md 纪律 6）。写"须在总盘按地区分配确定后精算，本文档不预设比例"。

概览表之后只对**有额外决策含义的环节**单独展开成节（通常是气候、本地正品文化、支付结构），其余不重复展开。

逐项核查内容见 `localization-checklist.md`。

## 第三章 品牌定位与竞品格局

### 3.1 核心判断：谁是红海，谁是空档

**先给一句话结论，再给资源分配百分比。** 没有百分比的"主推"是空话。

> 主推 [品类 A]，[品类 B] 次之，[品类 C] 只做搭售和引流。

| 品类 | 资源占比 | 角色 |
|---|---|---|
| | 60% | 主推。理由 |
| | 20% | 次推 |
| | 15% | 搭售与引流 |
| | 5% | 单季爆发，不是全年配比 |

⚠️ **必须紧跟一句标注**：

> 以上百分比指**运营与投放资源的分配方向**，不是货盘件数分配。实际能分到多少货取决于总盘在各市场之间的分配结果，尚未确定（见文末待确认第 N 条）。

判断红海/空档的依据要写出来：本土品牌占据的价格带、快时尚压在哪一档、本盘售价卡在什么位置、市场平均单品价是多少。空档赛道要说明"竞争者少、比价对象模糊"，并点出本盘落在这一档的哪个位置（上沿还是下沿）。

### 3.2 价格位置

用公开正价区间说话，把品牌卡在两个参照物之间：

| 品牌 | 公开价格 | 折合 | 消费者位置 |
|---|---|---|---|
| [下方参照] | | | 快时尚设计、入门价格 |
| **[本盘售价]** | | | 授权 Outlet |
| [品牌正价] | | | 国际品牌、可负担升级 |
| [上方参照] | | | Accessible luxury |

如果市场上已存在深折扣，必须补一句消费者预期判断：

> 官网常年挂折扣，实际价格优势会被压缩——折后价可能落到与本盘接近的区间。因此不能只靠价格，差异化必须建立在 [三个具体点] 上。

### 3.3 竞品四分组

不要平铺一堆品牌名。分四组，每组说清"与本品牌的重合点"和"竞争关系"：

| 竞品组 | 代表品牌 | 与本品牌重合点 | 竞争关系 |
|---|---|---|---|
| 核心品类竞品 | | | 直接竞品 |
| 品牌调性竞品 | | | 调性直接竞品 |
| 价格与流量参照 | | | 价格锚 |
| 本地强势品牌 | | | 本地强势竞品 |

**本地强势品牌那一组最容易漏，但最重要**——国际品牌调研常常只盯国际品牌，忽略本地已经占住心智和价格带的玩家。

### 3.4 渠道集中度

有些市场的"国际中端时尚"板块由单一分销商把控。这种结构必须单独成节，因为它**比任何市场规模数字都更能决定项目成败**。

要写清：

1. 这家分销商代理了哪些品牌、共多少个、隶属哪个集团
2. 冲击的不是单一品牌价盘，而是整个组合的价格心智 → 渠道阻力风险
3. 比价对象不是一个官方店，而是一张覆盖 N 个品牌的零售网络
4. 授权谈判的对手方议价能力

结尾一句：**这一条应在立项阶段就摆到台面上。**

### 3.5 需注意的竞争动态

**专查一件事：品牌方或分销商自己做不做线下特卖会 / Outlet / 奥莱？**

这是 SKILL.md 纪律 4 的第 3 条，最容易漏、杀伤力最大。查到了就单独成节：

```
**[分销商] 已在做线下 Outlet。**
年度 [特卖会名称]：N 个品牌（含本品牌）集中清仓，折扣标注最高 X%，
场地 [地点]，会期约 [时长]（[最近一次的日期]）。

**三点影响：**
1. 「品牌授权 Outlet」这个心智位置已被部分占据，且价格锚更低
2. 会期是否与你的大促窗口重叠
3. 消费者对"这个品牌可以很便宜"已有预期

**应对**：差异化不打价格（打不过），打特卖会给不了的三件事——
全年随时可买、送到家、断码稀缺（特卖会一年一次、限一城、需现场抢）。

**待办**：核实今年场次日期，投放排期避开或反向利用。
```

⚠️ 写完这一节，回流到第六章阻力表和一页结论（见 `delivery-gates.md` Gate A 反向规则）。

## 第四章 品牌当地现状与风险点

> 本章有否决权。以下任何一条不成立，第五章之后的内容都不需要执行。

### 4.1 现有布局

门店数量与位置（分首都圈/其他城市/奥特莱斯）、官方线上渠道、代言与本地内容活动。

**用门店覆盖度反推线上的战略地位**——这是最有说服力的一句话：

> N 家店意味着 [X] 个省级行政区只覆盖了 [Y] 座城市。线上是该品牌在当地唯一的规模化触达方式，而这个位置目前是空的。

本地化程度用深度而非有无来判断：

> 不是没有本地化，而是本地化存在但不够深、不够连续——有 [具体已有的东西]，但缺少 [具体缺失的东西]。

### 4.2 平台讨论度与消费者认知

**这一节回答的是"品牌名在当地线上现在是什么状态"**，和 4.1 的"官方开了几家店"是两件事。五个固定动作，缺一个都不完整。

**官方阵地盘点表**

| 阵地 | 状态 | 说明 |
|---|---|---|
| [平台A] 官方店 | 有 / 未检索到 | |
| [平台B] 官方店 | | |
| 品牌社媒号 | | 是本地运营还是搬运总部素材 |
| 独立站 | | 有没有本地域名 |

判断句式：如果姊妹品牌（同分销商）已开店而本品牌没开，那**不是政策问题，是优先级问题**——这是最明确的渠道空档信号。

⚠️ 公开检索有上限，结论要标"待人工核实"，并进文末数据缺口表。

**平台上品牌名的实际生态**

搜品牌名，看谁在卖、卖什么价。要产出**价格跨度倍数**：

> 在售链接卖家全为散户小店，无一家授权店。价格从 [最低] 到 [最高]，跨度 [N] 倍。

分三档判断：明显非正品的低价段 / 与本盘正面重叠的中价段 / 接近正价代购的高价段。

**这一节的产出是开店首月的任务定义**：

> 首月核心任务不是卖货，是成为 [搜索词] 结果页里唯一一个看起来像官方的卖家。

**认知排位**

不要笼统写"有知名度"。要在当地的同价位榜单里定位：

> 本地导购内容对该品牌的描述一致：[三到四个形容词]，心智集中在 [品类]，[另一品类] 几乎不被提及。在本地 [同价位榜单] 中通常排在 [A、B、C] 之后。

结论落到内容策略：

> 不需从零教育，但也借不到势。品牌名只负责"这是个国际品牌"，转化由授权、材质、做工、实拍承担；不做纯调性内容。

**舆论最大体量是什么**

搜品牌名的当地语内容，看**占据前排的是哪一类**。如果是"如何辨真假"而不是穿搭测评，说明：高仿量大 + 消费者下单前的主要心理活动是"这是不是假的"。这一条直接改写内容策略。

**平台信任本身有没有裂缝**

查当地论坛（越南 VOZ、泰国 Pantip、菲律宾 Reddit 等）对**平台官方店/Mall 店**的口碑。如果连官方 Mall 店都有假货投诉且高赞评论是"Mall 上假货多的是"，那么：

> "我们是 Mall 官方店"在当地说服力已被稀释，不能作为信任终点。

对应的信任 SOP 写在第七章，这里只写判断并指过去。

### 4.3 授权与渠道风险

逐项确认并写明证据来源：

- 谁是当地的独家经销商或总代？（常见于品牌官网的隐私政策、条款页面的公司主体署名，或分销商官网的自我表述原文）
- 品牌方有没有直营站点或直营旗舰店？
- 委托方的授权是否覆盖：本市场、线上销售、商标素材使用、店铺命名、广告渠道？

**这一节要产出一份"待确认清单"**，排第一条的永远是授权地域覆盖问题——不清楚则后面全部白做。

### 4.4 政策与合规风险

- 跨境免税门槛（de minimis）：金额、计价基础（CIF/FOB）、法条依据、**是否已被废止**
- 电商/直播相关立法：法定代表人、卖家身份核验、KOL/KOC 义务、平台代扣代缴
- 外资准入限制：是否影响本地开店/入驻资格
- 平台入驻资格与所需执照
- 广告与价格宣传的合规底线（原价标示、折扣措辞）

⚠️ **法规日期必须与今天比对。** 已生效的写成"即将生效"是最贵的低级错误。写明"该法已在执行期，不是待生效条款"。

政策类风险带时效窗口判断：

> 该红利正受压力（[具体动向]）→ 按 [12–18] 个月窗口规划，不要写成长期优势。

**合并结论**要落到模式选择：跨境店 vs 本地公司/本地仓，哪种更稳。

## 第五章 当地用户画像

### 5.1 核心人群

给出年龄、地域、收入门槛，然后写**那一句最重要的消费者洞察**——全案最值钱的通常就是这一句：

> [当地] 中产买不起 [顶奢]，[价格区间] 的国际品牌 [品类] 是性价比最高的身份符号。

明确标注这是主推品类能跑通的根本原因。

### 5.2 区域审美差异（投放必须分开）

如果市场有南北/东西的实质差异，用两列表说清：

| | **[区域A]** | **[区域B]** |
|---|---|---|
| **审美取向** | | |
| **主推商品** | | |
| **内容基调** | | |

### 5.3 分层画像

分层写，每层固定给这些字段：年龄、地域、收入、场景、心态、适合品类、内容触点、**优先级**。

- **画像 A**：核心成交人群，负责首轮规模 —— 优先级最高
- **画像 B**：由渠道结构决定优先级的人群（例如某平台用户结构更年轻）—— 第二，**注明优先级来自渠道结构而非偏好判断**
- **画像 C**：成熟人群 —— 第三，**建议独立测试，不与画像 B 的素材混投**
- **画像 D**：另一性别或另一品类的稳定盘 —— 第四，但有稳定价值

### 5.4 汇总

| 人群 | 购买理由 | 适合商品 | 内容特征 | 优先级 |
|---|---|---|---|---|

**必须写的纪律句**：

> 年龄不是简单截止线：[主力年龄段] 负责首轮规模，[成熟年龄段] 用独立货品和素材验证，不与年轻趋势素材混投。

理由：成熟人群的购买理由（品质、舒适、经典、容量、售后）和年轻人群（Logo、趋势、造型感）完全不同，混投会让两边的素材互相拉低转化，还会掩盖真实的人群价值。

## 第六章 市场机会判断

### 品类机会排序

| 品类 | 市场机会 | 货盘适配 | 主要限制 | 角色 |
|---|---|---|---|---|

必须跟一句限制说明：

> 最终优先级由"库存状态 × 可售数量 × 当地场景 × 广告后贡献毛利"共同决定，这也是后续会动态调整的地方。

### 机会 × 证据

| 机会 | 证据 |
|---|---|

这张表的价值在于强制每个机会挂一条证据。挂不上证据的机会，删掉。

### 阻力 × 证据 × 应对方向

| 阻力 | 证据 | 应对方向 |
|---|---|---|

**这张表比机会表更有价值**（多了应对方向列）。如果要精简文档，优先保留这张。

⚠️ 新增任何一条竞争动态或风险后，回来同步这张表。

### 结论句式

> 我们的机会不是在 [市场] 再卖一遍 [便宜商品]，而是用 [三点差异化]，吃下 [竞争对手] 够不到的 [价格带和城市]，主战场是 [品类]。

## 第七章 策略重点与落地

### 7.1 定位一句话

把整体策略压缩成一行：

> 「[品牌] 品牌授权 Outlet · [市场] 官方直发」

跟一句"不与谁争哪个位置"，和一句最高级别的叙事禁令。

### 7.2 品类与地域分盘

|  | 全国（各区域都上） | 只上 [某区域] |
|---|---|---|
| 主推 | | |
| 次推 | | — |
| 搭售引流 | | — |
| 不上 | — | [原因，只写一次] |

### 7.3 平台打法

每个平台一行，**格式是「角色定位（份额数字）：理由 + 动作」**：

- **[平台A] = 主成交与主内容（X%，品类份额 Y%）**：理由 + 具体动作
- **[平台B] = 主搜索与比价承接（X%）**：理由 + 具体动作
- **[平台C/D]：不做**
- 店铺形态优先做 Mall／官方店（附店铺数占比 vs GMV 占比的对比数字）

⚠️ **这一节的措辞必须和一页结论完全一致。** 两边写反是最常见的低级错误。

### 7.4 语言与信任

- **100% 本地语。** 商品标题、详情、客服、直播全本地语。英语普及率低的市场，英文页面直接掉转化
- **三条必上的信任元素**：授权文件/声明图放进**商品详情页**而非仅店铺简介；原厂吊牌 + 防伪码开箱视频，每个主推 SKU 至少一条；稀缺性表述（"每款每码仅 N 件，售完不补"）
- **售后条款高于平台标准，并作为转化素材**——在"退货被拒"是公开话题的市场，售后承诺本身就是转化理由
- **高频信任词**：给出本地语原词 + 中文释义，并注明哪些措辞在当地有合规禁区、哪些可以直说
- 客服语气：先确认问题，再给解决选项和时间；不公开争辩

### 7.5 价格与支付

只写第三章没写的：税负如何吃进定价、各支付方式的开关策略。**不重复价格位置**（那是 3.2）。

### 7.6 节奏（当地日历）

- 大促日期
- 发薪日节奏
- **年度最大窗口是哪一段，为什么**（通常是气候需求 + 大促 + 节庆送礼叠在一起）
- 节庆前的备货与备内容提前量

### 7.7 预算三档

| 档位 | 月投放 | 适用 |
|---|---|---|
| A 试水 | | 只跑主推品类，验证转化 |
| B 推荐 | | 双平台常态运营 |
| C 冲刺 | | 峰值月 |

必写一句：未做本地 CPC 实测，以上为量级建议，实际效率需以首月数据校准。

### 7.8 Roadmap

编号 Phase，每个 Phase 给动作链（用 → 连接）。

⚠️ **每个 Phase 的时间与交付当天比对。** 如果 Phase 0 的截止日已经很近或已过，要么改成相对表述（"立项后 N 周内"），要么加一条窗口警示：

> Phase 0 必须在 [日期] 之前完成，否则 [年度窗口] 赶不上，整盘顺延一年。

### 7.9 消费者偏好

段落 + 短列表，重点讲**内容与促销的响应方式**，不回头讲支付物流（那是第二章）。

引用调研时样本说明写成**一行括注**，不单独成段：

> （[来源]；样本 N 人，仅覆盖 [城市]，未标注年份，仅用于定性判断，不用于测算）

要点：促销有效但不能只看折扣、直播是决策终点不是冲动机器、真实内容负责建立信任、大促不能盲冲、履约确定性比指定快递重要。

### 7.10 文化与营销禁忌

编号列表，每条给出**边界而非口号**。必查项：

1. 地图与领土议题（多数东南亚市场的最高风险项）
2. 宗教与祭祀语境
3. 国旗、政治符号、领导人形象
4. IP、明星、音乐素材的商用授权
5. 节庆视觉不可套用邻国符号
6. 本地正品/产地叙事的雷区

详见 `localization-checklist.md` 的禁忌部分。

⚠️ 编号列表中间插入独立段落会让 markdown 重启计数，交付前检查编号连续性。

### 待客户确认（按优先级）

编号列表，第一条永远是授权地域覆盖。每条写成一个能被"是/否"回答的问题，并标注**不清楚会导致什么**：

> 1. **经销授权是否覆盖该市场？有无书面文件？**（不清楚则以上全部作废）

### 数据缺口与待办

| 缺口 | 影响 | 建议补法 |
|---|---|---|

**这张表是文档的诚实性所在**，也是所有"不预设数字"内容的落脚点。写法要求：

- 影响列写清它**决定什么**，不是笼统写"影响判断"

- 正文中所有的"待核实""未逐一核价"这类调研过程说明，都移到这张表里，不留在正文

## 可复用句式库

**点破样本偏差**
> （[来源]；样本 N 人，仅覆盖 [城市]，未标注年份，仅用于定性判断，不用于测算）

**代理指标免责**
> 这里的 [X]% 是 [口径] 的代理占比，不是销售份额。

**资产不可继承**
> 对委托方而言，不能继承这些关注者、评价、平台身份和历史数据；对自己的店铺而言，仍然是从零起步。

**价格带定性**
> 以上为建议测试价梯，不是市场平均价格，最终须按吊牌、最低售价限制和广告后毛利核算。

**未定的分配比例**
> [某项] 须在总盘按地区分配确定后，按材质与品类从原始库存表精算。本文档不预设比例。

**资源占比的必要标注**
> 以上百分比指运营与投放资源的分配方向，不是货盘件数分配。

**结论留可证伪口**
> 最终优先级必须由 [四个变量] 共同决定，这也是后续会动态调整策略的地方。

**本地化程度的非二元判断**
> 问题不是"零本地化"，而是本地化存在但不够深、不够连续。

**门店覆盖度反推线上地位**
> N 家店意味着 [X] 个省级行政区只覆盖了 [Y] 座城市。线上是该品牌唯一的规模化触达方式，而这个位置目前是空的。

**渠道空档的定性**
> 同一分销商已为姊妹品牌开店，说明不是政策问题，是优先级问题。

**平台信任已被稀释**
> "我们是 Mall 官方店"在当地说服力已被稀释，不能作为信任终点。

**过度简化的纠正**
> "[常见说法]"属于过度简化。[补充语境]；普通商品可以 [做法]，但涉及 [敏感场景] 时应由本地团队审核语境。

**法规时效**
> 该法已在执行期，不是待生效条款。
