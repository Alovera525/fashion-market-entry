## 开头·关于这份文档

紧跟标题。**每项一行，一行写不完就说明这项该精简，不要折成两行。**

```
**读者**：[决策方] + [执行团队]
**用途**：[某某站]立项决策依据，通过后作为执行基准
**否决点**：第[N]章。[三项硬前提]，任一不成立则第[N+1]章之后不执行
**汇率**：¥1 ≈ [X][当地货币]（[YYYY-MM] 取数），全文只用这一个
**比价基准**：本盘售价中位 [人民币] / [当地货币]
**口径**：市场规模均为[线上零售额 / GMV]、[含税 / 不含税]
**不含**：SKU 选品、月度排期、店铺命名与文案、成本精算与投放预算
**怎么读**：5 分钟 → 执行摘要；拍板 → 加读第[N]章；执行 → 加读第七章 + 文末待办清单
```

几个字段的作用：

- **读者** —— 决定语气和详略。两者兼有就明说兼有
- **否决点** —— 提前告诉读者哪一章能一票否决，他就知道该先读哪里
- **汇率 / 比价基准 / 口径** —— 全文的计量基础。读者看到后面任何一个本地价格都能自动换算判断"贵不贵"；锚点不给，全篇数字对中文读者就是抽象符号
- **不含** —— 防止客户拿这份文档去要它本来就没打算解决的东西
- **怎么读** —— 让读者自己选深度。头晕往往不是因为长，是因为不知道哪些可以不读

如需给吊牌 / 售价 / 最低价三个中位数，写成紧跟其后的一行，不单独成段：

> 本盘加权中位：吊牌 ¥799 / 3.089.000₫；售价（吊牌 40%）¥319 / 1.233.000₫；最低价 ¥159 / 615.000₫。

## 开头·执行摘要

**这是全文最重要的一块，也是客户唯一保证会读完的部分。** 它不是结论清单，是**交办清单**——执行团队只看这七行就能开工。

```
## 执行摘要

**窗口**：[N]月底前上线，赶[大促 + 季节需求]；错过顺延一年。
**平台**：主推[平台A]；[平台B]开店承接搜索与比价，不投引流；[平台C/D]不做。
**货**：主推[品类A]（[款式特征]）；从总盘划[品类B]过来做引流破零；[某品类]不上。
**投放**：[区域甲]与[区域乙]分开建投放包，不合并素材。
**打法**：[差异点1] / [差异点2]（[本地语境注解]）/ [差异点3]。
**人工待办**：[需要人盯的事1]；[需要人盯的事2]。
**红线**：[最高风险的那一条禁忌]，一律不用。
```

### 七个槽位各自回答什么

| 槽位 | 回答的问题 | 常见的写坏方式 |
|---|---|---|
| **窗口** | 什么时候必须动，错过会怎样 | 没有时间，读者感受不到紧迫性 |
| **平台** | 主次 + **明确不做什么** | 只写"主推 A、次推 B"，没说 B 具体承担什么、哪个不做 |
| **货** | 主推什么 + **款式特征** + 对总盘的要求 + 不上什么 | 只写品类不写款式（"主推女装"→ 该写"主推显身材女装：抹胸/束腰/露腰"）；或写成市场描述而不是对总盘的要求 |
| **投放** | 地域 / 人群的切分边界 | 笼统写"精准投放" |
| **打法** | 为什么买你，三点，带本地语境注解 | 写成品牌调性形容词 |
| **人工待办** | **机器判断不了、必须人盯的事** | 和文末待办清单混淆——这里只放执行期要持续关注的（天气、体型、场次） |
| **红线** | 碰了就出事的那一条 | 罗列一堆禁忌，等于没有重点 |

### 四条硬规则

1. **全是祈使句，不写判断句和理由。**"主推 TikTok Shop"是指令；"TikTok 份额已反超 Shopee"是判断——后者留给正文
2. **必须有"不做什么"。** 负向指令和正向一样重要，而且更省钱
3. **不出现数字。** 数字在正文，摘要只给动作。唯一例外是窗口里的日期
4. **七行以内，一个槽位一行。** 超了说明混进了论证，回去删

### 「人工待办」和文末清单的分工

**文末待办清单是唯一的总表**，同时容纳"待确认"和"待持续观察"两类，用 PoC 列区分。

**执行摘要的「人工待办」是这张表里持续观察类的一句话浓缩**，不是另一批事。写摘要时从文末清单里挑最重要的一两条压成一行，不要另起炉灶。

## 第一章 市场基本盘

### 1.1 购买力与地域分布

先给全国数据，再给首都圈/核心都市圈数据，两者的差值就是投放地域优先级的依据。

必查：人均 GDP、家庭月均收入（全国 vs 首都圈）、城镇化与收入分布。

**输出：线上投流地域排序**（这是本节的产出，不是可选项）

```
- P1：[首都及都市圈]（收入、品牌认知、平台消费和内容触达更集中）
- P2：[区域中心城市]（年轻消费者与内容测试价值）
- P2：[旅游城市]（若品牌已有旅游零售认知，但需说明应瞄准常住者还是游客）
```

旅游城市要特别注明：如果委托方没有当地线下门店，旅游客流吃不到，应优先瞄准当地常住者。

**若两个核心城市在气候或审美上有实质差异，这里就要说清"不合并成同一个投放包"**，并指向第五章的南北/东西差异表。

### 1.2 品类市场规模与趋势

表格结构：

| 品类 | 当地线上年销售额 | 线上化程度 |
|---|---|---|
| 时尚整体 | 本地货币（括注美元或人民币） | 百分比区间 |
| 其中服装 | | 占时尚大类比例 |
| 包袋及配饰 | | |
| 其中珠宝手表 | | |

同时补四项：

- **近 3 年增长趋势**：给年复合增速或逐年数字，判断是顺风还是逆风市场
- **平台 GMV 份额 + 同比变化**：变化方向比绝对值更重要（"由 61% 下滑到 53%"和"53%"是两个信号）
- **品类层面的平台份额**：全市场份额和时尚品类份额可能方向相反，**以品类份额为准**
- **官方店/Mall 店的店铺数占比 vs GMV 占比**：这一对数字直接说明市场是否向"官方授权"聚拢

### 1.3 客单价与价格错配

平台通常不公布客单价，用公开数据推算并把算式露出来：

| 项目 | 数值 | 折合 |
|---|---|---|
| 平台 GMV | | |
| 销量 | | |
| **平均单品价** | **GMV ÷ 销量** | |

> 按每单 1.4–1.6 件的行业经验区间计算，客单价约 [区间]。

然后做**错配比对**，差几倍写几倍：

> 单品口径：[本盘售价中位] ÷ [平均单品价] = [N] 倍；订单口径 = [M] 倍。

结论落到引流款：给出引流款目标价位（市场平均单品价的 1.5–2.6 倍，溢价由品牌身份支撑），并**反推回吊牌上限**，注明盘内符合条件的商品数量待核对。

**拿到平台内实测的真实成交价带后，回库存表实算三件事**（SKILL.md 纪律 5）：

| 要算的 | 写法 | 为什么 |
|---|---|---|
| 成交价带里可售几件 | 「售价 ≤[X] 的货：[N] 件 / [M] 款色」 | **0 件是否决性事实**——这条路物理上不存在，不是"需要努力" |
| 要进这个带需按吊牌几折 | 「须按吊牌 [X]–[Y]% 定价」 | 若低于常规折扣率，这就是**第一否决项**，要写进阻力表 |
| 各品类的实际折扣结构 | 「服装 = 吊牌 40%/20%；箱包 = 吊牌 50%/30%」 | 不同品类结构常不同，逐品类从表里核，不套单一比例 |

> ✅ 「总盘售价 ≤₱500 的货：0 件、0 款色 → 跟着往下打这条路物理上不存在。」
> ✅ 「要进官方成交带 ₱699–2,499，须按吊牌 25–35% 定价，而非常规 40%——毛利能否成立是第一否决项。」

### 1.4 价格带假设

三档结构：

| 档位 | 价格区间 | 折合 | 承担角色 |
|---|---|---|---|
| 引流款 | | | 破零与评价积累 |
| 主成交带 | | | 主力品类 |
| 高客单带 | | | 需更强正品证明、实拍与分期承接 |

必写一句话：

> 以上为建议测试价梯，不是市场平均价格，最终须按吊牌、最低售价限制和广告后毛利核算。

## 第二章 本地消费习惯与产品细节

固定用三列表，六个环节。每行必须落到动作——这个结构的作用就是防止写成消费者观察散文。

| 环节 | 本地特征 | ACTION |
|---|---|---|
| **气候** | 温度带、雨季长度、有无温差、湿度 | 哪些品类是全年货、哪些没有自然需求 |
| **尺码** | 网购退货的高风险点 | 本地语尺码表 + 厘米 + 模特身高体重 + 版型标签 + 试穿视频 |
| **支付** | 主流支付方式与渗透率 | 展示平台实际开放的支付方式；COD 拒收要单独监控 |
| **物流** | 时效标配、二三线时长 | 按准时率、破损率、偏远覆盖选承运商 |
| **促销** | 发薪日节奏、大促心智、年度峰值 | 用发薪日与平台大促做限时权益，设定最低成交价 |
| **内容** | 短视频/直播/社交对发现的影响 | 每个核心 SKU 至少一条试穿、一条搭配、一条尺码答疑 |

**气候那一行是杀伤力最大的一行**。热带市场（全年无温差）意味着秋冬服装在平原地区没有自然需求——这可能直接砍掉一半货盘。但注意两点：

1. 包袋的"秋冬"往往是**设计季而非气候属性**，要看材质（有无呢料、毛绒）再决定是否排除，不要按季节标签一刀切
2. **有真实冬季的区域要单独开盘，并划清三条边界**：只在哪些地区成立、只到哪一层（轻外层还是厚外套）、窗口几个月

⚠️ **不要给可用件数或占比的估算**（SKILL.md 纪律 6）。写"须在总盘按地区分配确定后精算，本文档不预设比例"。

概览表之后只对**有额外决策含义的环节**单独展开成节（通常是气候、本地正品文化、支付结构），其余不重复展开。

逐项核查内容见 `localization-checklist.md`。

## 第三章 品牌定位与竞品格局

### 3.1 核心判断：谁是红海，谁是空档

**先给一句话结论，再给资源分配百分比。** 没有百分比的"主推"是空话。

> 主推 [品类 A]，[品类 B] 次之，[品类 C] 只做搭售和引流。

| 品类 | 资源占比 | 角色 |
|---|---|---|
| | 60% | 主推。理由 |
| | 20% | 次推 |
| | 15% | 搭售与引流 |
| | 5% | 单季爆发，不是全年配比 |

⚠️ **必须紧跟一句标注**：

> 以上百分比指**运营与投放资源的分配方向**，不是货盘件数分配。实际能分到多少货取决于总盘在各市场之间的分配结果，尚未确定（见文末待办清单）。

判断红海/空档的依据要写出来：本土品牌占据的价格带、快时尚压在哪一档、本盘售价卡在什么位置、市场平均单品价是多少。空档赛道要说明"竞争者少、比价对象模糊"，并点出本盘落在这一档的哪个位置（上沿还是下沿）。

### 3.2 价格位置

用公开正价区间说话，把品牌卡在两个参照物之间：

| 品牌 | 公开价格 | 折合 | 消费者位置 |
|---|---|---|---|
| [下方参照] | | | 快时尚设计、入门价格 |
| **[本盘售价]** | | | 授权 Outlet |
| [品牌正价] | | | 国际品牌、可负担升级 |
| [上方参照] | | | Accessible luxury |

如果市场上已存在深折扣，必须补一句消费者预期判断：

> 官网常年挂折扣，实际价格优势会被压缩——折后价可能落到与本盘接近的区间。因此不能只靠价格，差异化必须建立在 [三个具体点] 上。

### 3.3 竞品四分组

不要平铺一堆品牌名。分四组，每组说清"与本品牌的重合点"和"竞争关系"：

| 竞品组 | 代表品牌 | 与本品牌重合点 | 竞争关系 |
|---|---|---|---|
| 核心品类竞品 | | | 直接竞品 |
| 品牌调性竞品 | | | 调性直接竞品 |
| 价格与流量参照 | | | 价格锚 |
| 本地强势品牌 | | | 本地强势竞品 |

**本地强势品牌那一组最容易漏，但最重要**——国际品牌调研常常只盯国际品牌，忽略本地已经占住心智和价格带的玩家。

### 3.4 渠道集中度

有些市场的"国际中端时尚"板块由单一分销商把控。这种结构必须单独成节，因为它**比任何市场规模数字都更能决定项目成败**。

要写清：

1. 这家分销商代理了哪些品牌、共多少个、隶属哪个集团
2. 冲击的不是单一品牌价盘，而是整个组合的价格心智 → 渠道阻力风险
3. 比价对象不是一个官方店，而是一张覆盖 N 个品牌的零售网络
4. 授权谈判的对手方议价能力

结尾一句：**这一条应在立项阶段就摆到台面上。**

### 3.5 需注意的竞争动态

**专查一件事：品牌方或分销商自己做不做线下特卖会 / Outlet / 奥莱？**

这是 SKILL.md 纪律 4 的第 3 条，最容易漏、杀伤力最大。查到了就单独成节：

```
**[分销商] 已在做线下 Outlet。**
年度 [特卖会名称]：N 个品牌（含本品牌）集中清仓，折扣标注最高 X%，
场地 [地点]，会期约 [时长]（[最近一次的日期]）。

**三点影响：**
1. 「品牌授权 Outlet」这个心智位置已被部分占据，且价格锚更低
2. 会期是否与你的大促窗口重叠
3. 消费者对"这个品牌可以很便宜"已有预期

**应对**：差异化不打价格（打不过），打特卖会给不了的三件事——
全年随时可买、送到家、断码稀缺（特卖会一年一次、限一城、需现场抢）。

**待办**：核实今年场次日期，投放排期避开或反向利用。
```

⚠️ 写完这一节，回流到第六章阻力表和执行摘要（见 `delivery-gates.md` Gate A 反向规则）。

## 第四章 品牌当地现状与风险点

> 本章有否决权。以下任何一条不成立，第五章之后的内容都不需要执行。

### 4.1 现有布局

门店数量与位置（分首都圈/其他城市/奥特莱斯）、官方线上渠道、代言与本地内容活动。

**用门店覆盖度反推线上的战略地位**——这是最有说服力的一句话：

> N 家店意味着 [X] 个省级行政区只覆盖了 [Y] 座城市。线上是该品牌在当地唯一的规模化触达方式，而这个位置目前是空的。

本地化程度用深度而非有无来判断：

> 不是没有本地化，而是本地化存在但不够深、不够连续——有 [具体已有的东西]，但缺少 [具体缺失的东西]。

### 4.2 平台讨论度与消费者认知

**这一节回答的是"品牌名在当地线上现在是什么状态"**，和 4.1 的"官方开了几家店"是两件事。五个固定动作，缺一个都不完整。

**官方阵地盘点表**

| 阵地 | 状态 | 说明 |
|---|---|---|
| [平台A] 官方店 | 有 / **本文档无法核实，须平台内实测** | |
| [平台B] 官方店 | | |
| 品牌社媒号 | | 是本地运营还是搬运总部素材 |
| 独立站 | | 有没有本地域名 |

⚠️ **状态列只有两种合法值**：确凿的"有"（拿到截图或官方链接），或"本文档无法核实，须平台内实测"。**不写"未检索到"**（见 SKILL.md 证据地基第一条）。未核实的行不得推出任何结论，直接进文末待办清单，PoC 我方。

拿到实测确认后才能用的判断句式：如果姊妹品牌（同分销商）已开店而本品牌没开，那**不是政策问题，是优先级问题**。

**平台上品牌名的实际生态**

搜品牌名，**看销量不只看价格**——价格只说明有人挂，销量说明有人买。口径要分清：搜索页通常标 `Sold/Month`（近 30 天），店铺页标累计 `sold`。

| 搜索词 | 有销量的价格区间 | 卖家特征 |
|---|---|---|
| [品牌名] + [品类] | | 本地散户 / 跨境卖家 / 仿品集群 |

仿品集群有明显特征：店名用字符变体规避风控（`GU3SS` `GUE$$`），话术用 `Ori` `overrun` `reject stain`，地址高度集中在同一个镇。

**做官方店 vs 搜索页的对照，这一节的产出是「流量从哪来」**：

> 官方 T 恤 ₱2,298 累计 6 件 vs 仿品店 ₱309 累计 10,000+ 件 → 搜索页是仿品价格战场，正价必输。**不投搜索关键词广告，流量必须从内容来。**

若官方缺位、搜索页全是散户，产出改为首月任务定义：

> 首月核心任务不是卖货，是成为 [搜索词] 结果页里唯一一个看起来像官方的卖家。

**认知排位**

不要笼统写"有知名度"。要在当地的同价位榜单里定位：

> 本地导购内容对该品牌的描述一致：[三到四个形容词]，心智集中在 [品类]，[另一品类] 几乎不被提及。在本地 [同价位榜单] 中通常排在 [A、B、C] 之后。

结论落到内容策略：

> 不需从零教育，但也借不到势。品牌名只负责"这是个国际品牌"，转化由授权、材质、做工、实拍承担；不做纯调性内容。

**舆论最大体量是什么**

搜品牌名的当地语内容，看**占据前排的是哪一类**。如果是"如何辨真假"而不是穿搭测评，说明：高仿量大 + 消费者下单前的主要心理活动是"这是不是假的"。这一条直接改写内容策略。

**平台信任本身有没有裂缝**

查当地论坛（越南 VOZ、泰国 Pantip、菲律宾 Reddit 等）对**平台官方店/Mall 店**的口碑。如果连官方 Mall 店都有假货投诉且高赞评论是"Mall 上假货多的是"，那么：

> "我们是 Mall 官方店"在当地说服力已被稀释，不能作为信任终点。

对应的信任 SOP 写在第七章，这里只写判断并指过去。

### 4.3 授权与渠道风险

逐项确认并写明证据来源：

- 谁是当地的独家经销商或总代？（常见于品牌官网的隐私政策、条款页面的公司主体署名，或分销商官网的自我表述原文）
- 品牌方有没有直营站点或直营旗舰店？
- 委托方的授权是否覆盖：本市场、线上销售、商标素材使用、店铺命名、广告渠道？

**这一节要产出一份"待确认清单"**，排第一条的永远是授权地域覆盖问题——不清楚则后面全部白做。

### 4.4 政策与合规风险

- 跨境免税门槛（de minimis）：金额、计价基础（CIF/FOB）、法条依据、**是否已被废止**
- 电商/直播相关立法：法定代表人、卖家身份核验、KOL/KOC 义务、平台代扣代缴
- 外资准入限制：是否影响本地开店/入驻资格
- 平台入驻资格与所需执照
- 广告与价格宣传的合规底线（原价标示、折扣措辞）

⚠️ **法规日期必须与今天比对。** 已生效的写成"即将生效"是最贵的低级错误。写明"该法已在执行期，不是待生效条款"。

政策类风险带时效窗口判断：

> 该红利正受压力（[具体动向]）→ 按 [12–18] 个月窗口规划，不要写成长期优势。

**合并结论**要落到模式选择：跨境店 vs 本地公司/本地仓，哪种更稳。

## 第五章 当地用户画像

### 5.1 核心人群

给出年龄、地域、收入门槛，然后写**那一句最重要的消费者洞察**——全案最值钱的通常就是这一句：

> [当地] 中产买不起 [顶奢]，[价格区间] 的国际品牌 [品类] 是性价比最高的身份符号。

明确标注这是主推品类能跑通的根本原因。

### 5.2 区域审美差异（投放必须分开）

如果市场有南北/东西的实质差异，用两列表说清：

| | **[区域A]** | **[区域B]** |
|---|---|---|
| **审美取向** | | |
| **主推商品** | | |
| **内容基调** | | |

### 5.3 分层画像

分层写，每层固定给这些字段：年龄、地域、收入、场景、心态、适合品类、内容触点、**优先级**。

- **画像 A**：核心成交人群，负责首轮规模 —— 优先级最高
- **画像 B**：由渠道结构决定优先级的人群（例如某平台用户结构更年轻）—— 第二，**注明优先级来自渠道结构而非偏好判断**
- **画像 C**：成熟人群 —— 第三，**建议独立测试，不与画像 B 的素材混投**
- **画像 D**：另一性别或另一品类的稳定盘 —— 第四，但有稳定价值

### 5.4 本地审美与选品原则

**这一节的产出优先级高于品类配比。** 品类逻辑说"包袋尺码风险低所以先做包"，审美判断说"这个市场买的是上身好看"——**后者赢**。

拿到商品截图或官方店动销榜时，**逐个读款式，不能只统计价格和销量**。输出必须是可执行的选品语言：

> ✅ 女装 = 抹胸 / 束腰 / 单肩 / 吊带 / 露腰短款 / 亮片 / 连体 / 修身，**没有一件是宽松保守基础款**。
> ✅ 男装 = 够花：花衬衫、刺绣外套动销最高，素色款明显更低。
> ❌ 「年轻女性追求时尚与个性表达」——这句话在任何国家都成立，等于没写。

男装女装分开写，最后给一句总的审美判断：

> [市场] 买的是"[一句话审美]"，优先级高于品类逻辑。

**判据：能不能拿这段话直接回货盘里挑款？** 挑不出来就是没写到位，回去重写。

⚠️ 这一节依赖平台内实测数据。拿不到截图时，**不要靠品类逻辑或气候倒推审美**——写"待实测"，进文末待办清单，不要编。

### 5.5 汇总

| 人群 | 购买理由 | 适合商品 | 内容特征 | 优先级 |
|---|---|---|---|---|

**必须写的纪律句**：

> 年龄不是简单截止线：[主力年龄段] 负责首轮规模，[成熟年龄段] 用独立货品和素材验证，不与年轻趋势素材混投。

理由：成熟人群的购买理由（品质、舒适、经典、容量、售后）和年轻人群（Logo、趋势、造型感）完全不同，混投会让两边的素材互相拉低转化，还会掩盖真实的人群价值。

## 第七章 策略重点与落地

### 7.1 定位一句话

把整体策略压缩成一行：

> 「[品牌] 品牌授权 Outlet · [市场] 官方直发」

跟一句"不与谁争哪个位置"，和一句最高级别的叙事禁令。

### 7.2 品类与地域分盘

|  | 全国（各区域都上） | 只上 [某区域] |
|---|---|---|
| 主推 | | |
| 次推 | | — |
| 搭售引流 | | — |
| 不上 | — | [原因，只写一次] |

### 7.3 平台打法

每个平台一行，**格式是「角色定位（份额数字）：理由 + 动作」**：

- **[平台A] = 主成交与主内容（X%，品类份额 Y%）**：理由 + 具体动作
- **[平台B] = 主搜索与比价承接（X%）**：理由 + 具体动作
- **[平台C/D]：不做**
- 店铺形态优先做 Mall／官方店（附店铺数占比 vs GMV 占比的对比数字）

⚠️ **这一节的措辞必须和执行摘要的「平台」那行完全一致。** 两边写反是最常见的低级错误。

### 7.4 语言与信任

- **100% 本地语。** 商品标题、详情、客服、直播全本地语。英语普及率低的市场，英文页面直接掉转化
- **三条必上的信任元素**：授权文件/声明图放进**商品详情页**而非仅店铺简介；原厂吊牌 + 防伪码开箱视频，每个主推 SKU 至少一条；稀缺性表述（"每款每码仅 N 件，售完不补"）
- **售后条款高于平台标准，并作为转化素材**——在"退货被拒"是公开话题的市场，售后承诺本身就是转化理由
- **高频信任词**：给出本地语原词 + 中文释义，并注明哪些措辞在当地有合规禁区、哪些可以直说
- 客服语气：先确认问题，再给解决选项和时间；不公开争辩

### 7.5 价格与支付

只写第三章没写的：税负如何吃进定价、各支付方式的开关策略。**不重复价格位置**（那是 3.2）。

### 7.6 节奏（当地日历）

- 大促日期
- 发薪日节奏
- **年度最大窗口是哪一段，为什么**（通常是气候需求 + 大促 + 节庆送礼叠在一起）
- 节庆前的备货与备内容提前量

**本节末尾附一段预算说明，不单独设节**（调研阶段没有预算节）：

> 投放预算须在品类结构与销量预估确定后单独测算，并结合总预算在各地区间的分配结果。本文档不给预算数字。原因与货盘分配比例相同：总预算同样要在各地区之间分配、比例尚未确定；且合理的投放量要等"主推品类预计销售额 × 各品类占比"出来才能倒推。此外若目标平台费率近期有过调整（见第一章），任何在此之前的投放效率假设都需重新校准。

平台费率调整那半句只在确有其事时写，没有就删掉。这段同时要列进文末待办清单，PoC 写"双方"。

### 7.7 Roadmap

编号 Phase，每个 Phase 给动作链（用 → 连接）。

⚠️ **每个 Phase 的时间与交付当天比对。** 如果 Phase 0 的截止日已经很近或已过，要么改成相对表述（"立项后 N 周内"），要么加一条窗口警示：

> Phase 0 必须在 [日期] 之前完成，否则 [年度窗口] 赶不上，整盘顺延一年。

### 7.8 消费者偏好

段落 + 短列表，重点讲**内容与促销的响应方式**，不回头讲支付物流（那是第二章）。

引用调研时样本说明写成**一行括注**，不单独成段：

> （[来源]；样本 N 人，仅覆盖 [城市]，未标注年份，仅用于定性判断，不用于测算）

要点：促销有效但不能只看折扣、直播是决策终点不是冲动机器、真实内容负责建立信任、大促不能盲冲、履约确定性比指定快递重要。

### 7.9 文化与营销禁忌

编号列表，每条给出**边界而非口号**。必查项：

1. 地图与领土议题（多数东南亚市场的最高风险项）
2. 宗教与祭祀语境
3. 国旗、政治符号、领导人形象
4. IP、明星、音乐素材的商用授权
5. 节庆视觉不可套用邻国符号
6. 本地正品/产地叙事的雷区

详见 `localization-checklist.md` 的禁忌部分。

⚠️ 编号列表中间插入独立段落会让 markdown 重启计数，交付前检查编号连续性。

## 文末·待办清单

一张表，四列。原来的「待客户确认」和「数据缺口」是同一件事的两半——都是"还没定、定了才能往下走"，合并。

排序：**先待确认**（否决性的最前），**再待持续观察**。

| 待办 | 影响 | PoC | 怎么补 |
|---|---|---|---|
| 经销授权是否覆盖该市场，有无书面文件 | 卡着全案 | 客户 | 提供授权协议原件 |
| 总盘按地区的分配比例 | 卡着[某区域]能否单独开盘 | 双方 | 客户定比例 → 我方从库存表按材质精算。**当前无估算值** |
| 预估综合成本（税负 + 投流 + 售价） | 卡着定价梯度能不能跑通 | 双方 | 客户给成本底价与税务口径 → 我方按平台费率与投流假设试算 |
| [分销商]今年特卖会场次日期 | 卡着大促窗口是避开还是反用 | 我方 | 人工核实分销商官网与社媒 |
| 当地天气预警的及时预告（技术集成探索） | 卡着秋冬盘上不上、什么时候上 | 我方 | 探索接入天气预警数据源，替代每年人工看 |
| 节庆日历的年度更新与提前量提醒 | 卡着备货与备内容的提前量 | 我方 | 逐年核对农历与伊斯兰历节日到具体那天 |

---

### 什么才算真待办

三条**同时满足**才进这张表：

1. **只有别人能给答案** —— 客户手里的信息、未来才发生的事、需要人工或线下确认的事
2. **它卡着一个具体决策** —— 不给答案，就有一件事做不了
3. **在职责范围内** —— 开头「不含」里声明过的，不进

**持续观察类也是真待办**：天气、节庆、特卖会场次都是外部变量，机器判断不了、每年都要重新看。写它们的时候优先写成"**怎么让它自动化或被及时提醒**"，而不是"每年人工看一次"——前者是能推进的工作项，后者只是个提醒便签。

### 三类伪待办，一条都不要写

**A · 自己的活没干完**

> ❌ 「时尚品类份额 53.1%／46.1% 的原始统计期与口径」
> ❌ 「某数据商分平台份额的原始数据」

这不是待办，是**调研没做完**。要么现在查清楚，要么在正文里写明"该数字来源为 X、口径为 Y，未能取得更细拆分"——**写在正文，不进清单**。把自己的活挂到清单上，客户会以为要他去办。

**B · 超出职责边界**

> ❌ 「确定店铺命名方案」
> ❌ 「组织分工与人员配置」

客户自己会拍板的事，不要放进他的待办里当作是你交办的（见 SKILL.md 职责边界）。

**C · 执行期的操作细节**

> ❌ 「引流款候选中"有图可直接上架"的比例」

这是上线后的运营 checklist，不是立项调研的待办。

### 四条写法规则

1. **每条要能被"是/否"或一个数字回答，或者是一件有完成态的工作。** 不写"研究一下当地物流"这种没有终点的条目
2. **PoC 只有三种**：`客户` / `我方` / `双方`。写"双方"时必须在「怎么补」列写清各自负责哪一半——否则等于没人负责
3. **影响列写它卡着什么决策**，不写"影响判断"这种废话
4. **未定的分配比例，「怎么补」列必须标"当前无估算值"**（纪律 6 的落脚点）

**这张表是文档的诚实性所在，但它只该有真事。** 清单越短越可信；塞满了自己的活和越界的事，客户就不会认真看任何一条。

正文中的"待核实""未逐一核价"这类过程说明，先判断属不属于 A 类——是的话改写进正文，不是的话才进这张表。

## 可复用句式库

**点破样本偏差**
> （[来源]；样本 N 人，仅覆盖 [城市]，未标注年份，仅用于定性判断，不用于测算）

**代理指标免责**
> 这里的 [X]% 是 [口径] 的代理占比，不是销售份额。

**资产不可继承**
> 对委托方而言，不能继承这些关注者、评价、平台身份和历史数据；对自己的店铺而言，仍然是从零起步。

**价格带定性**
> 以上为建议测试价梯，不是市场平均价格，最终须按吊牌、最低售价限制和广告后毛利核算。

**未定的分配比例**
> [某项] 须在总盘按地区分配确定后，按材质与品类从原始库存表精算。本文档不预设比例。
