# 交付闸门

四道闸门，各自绑定一个时刻。**不要全部堆到交付前**——Gate 0 的错误发现得越晚，返工面越大。

| 闸门 | 什么时候过 |
|---|---|
| **Gate 0 · 内容** | 每写完一章立刻过 |
| **Gate A · 去重** | 全文初稿完成、开始改稿时 |
| **Gate B · 精简** | 去重之后 |
| **Gate C · 四轮核对** | 交付前，一轮都不能跳 |

审查别人写的调研文档时，从 Gate 0 开始整份走一遍（见文末）。

---

## Gate 0 · 每写完一章立刻过

括号里是 SKILL.md 对应的纪律编号。

### 任何一章都要问

- [ ] 这一章的每个数字都归过**数字三分法**的类了吗？
- [ ] 有没有把估算写成事实陈述？推算的有没有把算式露出来？（纪律 1）
- [ ] 文档里有没有出现"一级/二级/三级信源"这类等级标签？**不该有。**（纪律 1）
- [ ] 引用的调查有没有一行括注写清样本构成、能代表谁不能代表谁？（纪律 2）
- [ ] 关注者 / 评分 / 榜位类数据有没有加"代理指标，不是销售份额"的免责？（纪律 3）
- [ ] 每个判断有没有带限制条件、说清推翻它需要什么证据？（纪律 7）
- [ ] **有没有给出还没确定的库存分配比例？一个都不该有。**（纪律 6）

### 写完第一章

- [ ] 平台平均客单价 vs 商品价格中位数的比对做了吗？差几倍写了吗？（纪律 5）
- [ ] 引流款价位反推回吊牌上限了吗？取值是不是过度保守？盘内符合条件的数量核对了吗？
- [ ] 价格带三档写明是"建议测试价梯，不是市场平均价格"了吗？
- [ ] 线上投流地域排序给出来了吗？（这是本章的产出，不是可选项）

### 写完第二章

- [ ] 六个环节每行都落到具体动作了吗？还是写成了消费者观察散文？
- [ ] 包袋的"秋冬"是按材质判断的，还是按季节标签一刀切了？
- [ ] 有真实冬季的区域，三条边界（哪些地区 / 到哪一层 / 窗口几个月）划清了吗？

### 写完第三章

- [ ] 有没有查品牌官方店的**实际 sale 价**，不只是正价？（纪律 4）
- [ ] **有没有查品牌方或分销商自己办不办线下特卖会 / Outlet？打到几折？会期压不压你的大促窗口？**（纪律 4，最容易漏的一条）
- [ ] 资源分配百分比后面有没有紧跟"这是投放与运营资源方向，不是货盘件数"的标注？
- [ ] 竞品四分组里的**本地强势品牌**那一组有没有漏？

### 写完第四章

- [ ] 否决性风险（授权地域覆盖、外资准入、品牌方直营占位）写完了吗？是不是写在策略之前？
- [ ] 有没有暗示新店能继承品牌的关注者、评价、平台身份或历史数据？（纪律 4）
- [ ] 本地化程度是不是写成了二元结论？应该写**深度与连续性**。
- [ ] 法规日期与今天比对过了吗？（详见 Gate C 第二轮）

### 写完第五章

- [ ] 人群画像有没有退化成一条年龄截止线？
- [ ] 每层有没有给优先级？优先级来自渠道结构还是偏好判断，说清了吗？

### 写完第六、七章

- [ ] 机会表里每条机会都挂上证据了吗？挂不上的删掉了吗？
- [ ] 阻力表的"应对方向"列填满了吗？
- [ ] 平台主次的措辞和一页结论完全一致吗？（两边写反是最常见的低级错误）
- [ ] 文化禁忌有没有把常见说法过度简化？（对照 `localization-checklist.md` 第九节，给边界不给口号）

## Gate A · 去重：代号引用制

调研文档最常见的可读性问题是同一件事在三个章节里各说一遍，越读越累，还容易前后不一致。

**规则：每类信息只有一个法定位置，其他章节只能引用不能重述。同一个数字全文只完整出现一次。**

| 信息 | 法定位置 | 别处怎么提 |
|---|---|---|
| 竞品数字（关注者、评分、价格区间） | 第三章 | 第六章只引结论，不重列数字 |
| 支付、物流、尺码细节 | 第二章 | 第七章只讲内容与促销的响应方式 |
| 价格带三档 | 第一章提出 | 第三章对标竞品验证，第七章不再重列 |
| 人群属性（年龄、场景、心态） | 第五章 | 其他章节只写"画像 A"，不重述属性 |
| 信任建设的具体 SOP | 第七章·语言与信任 | 第四章讨论度节只写判断，SOP 指过去 |

写完通读一遍，凡是发现某个数字出现第二次，就改成短语指代。

### 反向规则：新增内容必须回流

去重管的是"别重复"，但改稿时更常见的错误是**"新增了却没同步"**。任何时候新加一节或一条判断，必须回头检查这四个位置：

1. **一页结论**——这条够不够重要，要不要进
2. **机会 / 阻力汇总表**——新的阻力有没有加进去、带上应对方向
3. **数据缺口与待办**——新引出的待核实项有没有登记
4. **章节交叉引用编号**——插入新节后，后续编号和全文的"见 X.X"有没有跟着改

## Gate B · 精简：什么算"纯重复"

调研文档超过 10 页，客户就开始跳读。原则是**只删重复，不删独有信息**。

**可以删：**

- 同一个结论出现第三次（第一次是正文、第二次是汇总表，第三次一定是冗余）
- 汇总表与正文段落逐条对应——留表删段，或留段删表
- 已经有一页结论后，各章开头的"本章要说明什么"过渡段
- 调研过程与推理心路混在正文里（"未逐一核价，建议抽样核对"这类）——移进文末数据缺口表
- 同一个限制条件在相邻两节各写一遍（例如"南越全年 31–33°C 不上秋冬"写了三次）
- 概览表里已有的行，下面又展开成一整节且没有新信息

**不能删：**

- 带"应对方向"列的阻力表（比纯陈述的机会表有独立价值）
- 合规、授权、文化禁忌——这些是硬约束，重复一次也比漏掉强
- 任何一处独有的数字、日期、来源

**删完后独有信息要有落脚点**：删段落时，其中的独有判断要以注或并表的方式保留下来，不能跟着段落一起消失。

## Gate C · 交付前四轮核对

按顺序过，一轮都不能跳。

### 第一轮 · 数字

- [ ] 汇率用**两个独立来源**核（Wise、XE），偏差 >1% 就更新
- [ ] 所有货币换算**逐项反算**一遍，不要只抽查
- [ ] 所有倍数、百分比、区间关系重算（"9.2 倍""1.5–2.6 倍"这类最容易错）
- [ ] 隐含汇率是否自洽——文档同时出现本地币 / 人民币 / 美元时，三者的隐含汇率必须互相对得上
- [ ] 反推类数字取值是否过度保守（纪律 5）
- [ ] 货币符号位置与千位分隔符是否符合当地惯例（越南、印尼用点分隔；泰、菲、马、港台用逗号）

### 第二轮 · 时间

- [ ] **法规生效日期与今天比对**——已生效的不能写成"即将生效"。这是最贵的低级错误
- [ ] 节庆日期核对到具体那一天（农历与伊斯兰历节日尤其）
- [ ] **Roadmap 每个 Phase 与今天比对**——"8 月底前完成"在交付日是 8 月 14 号时就已经不现实。要么改成相对表述（"立项后 N 周内"），要么加一条窗口警示说明赶不上会怎样
- [ ] 所有平台数据快照有没有标注日期

### 第三轮 · 一致性与逻辑

- [ ] **一页结论逐条回正文核对措辞**——最容易出现的错是两边平台主次写反、优先级排序不一致
- [ ] 新增的内容有没有回流到四个汇总位置（见 Gate A 反向规则）
- [ ] 同一个判断在不同章节的表述有没有互相矛盾
- [ ] 一页结论里有没有混进解释性文字（出现"因为…所以…"就该压缩）
- [ ] 一页结论的条数、排序、"详见章节"挂链是否符合 `output-template.md` 的四条硬规则

**逻辑回溯**——一个动作，拿一页结论逐条倒推。"详见章节"那一列就是逻辑链，查它等于查逻辑：

- [ ] 它挂的那一章，**真的产出了这个判断吗**？还是只顺带提了一句
- [ ] 有没有跳步——**结论比证据强**？（查到"份额 53% 且在下滑"，写成"该平台会被取代"就是跳步）
- [ ] **如果那一章的数字改了，这条结论会不会跟着变？** 不会变，说明它其实不依赖那一章，挂错了。这一问最能揪出"看起来有依据、其实是拍的"结论
- [ ] **否决点闭环**：第四章说了"某条不成立则后面作废"，第七章有没有照常给出完整策略却只字不提这个前提？两处并存就是结构性自相矛盾，读者会不知道到底做不做

### 第四轮 · 结构与可读性

- [ ] Markdown 链接语法有没有炸（尤其中文标点混在 `[]()` 里）
- [ ] 有序列表编号是否连续（中间插入段落会让 markdown 重启计数）
- [ ] 章节编号有没有跳号（4.2 之后直接 4.4、5.3 之后直接 5.5）
- [ ] **标题层级有没有超过两级**（出现 `4.2.3` 就改成黑体列表项）
- [ ] **每节开头有没有黑体结论句**——只扫这些黑体句，能不能读出全文骨架
- [ ] **关键术语有没有出现两种叫法**（"主战场平台"和"核心平台"混用）
- [ ] 有没有写章末小结（一页结论已经汇总过，删掉）
- [ ] 开头「关于这份文档」里有没有那三行阅读路径
- [ ] 表格列数是否对齐、表头是否完整
- [ ] 每个表格是不是真的在做对比，而不是在排版（对照 SKILL.md 表格规则）

## 审查别人写的调研文档

不重写章节结构，除非结构本身导致漏判。按 Gate 0 → A → B → C 顺序整份走一遍，另加三条：

1. **客户旧稿里的数字全部重新审一遍。** 客户自己写过的估算不等于已确认——逐个问"这个现在还成立吗、它是不是一个还没定的东西"
2. **先找否决性风险有没有被埋在后面。** 授权覆盖、外资准入这类内容若出现在策略之后，先把它提前
3. **先报结构问题再报细节。** 结构一改，很多细节意见会自动作废
